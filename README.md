# Remix of TILE Board Game Café Dubai

Create a sleek, modern, dynamic, scroll-based website for a board-game café called “TILE.”
The design style should be minimal, premium, warm, and community-oriented with flowing scroll animations, parallax sections, and clean typography. Use TILE’s brand colors in a soft matcha/sage palette with deep green accents.

Overall Design Style

Minimal Japanese–Scandinavian influence

Smooth scroll animations

Parallax photo sections

Large visuals of food, drinks, board games, and the space

Rounded edges, airy spacing, modern icons

A warm, welcoming community café vibe
